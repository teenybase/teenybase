# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: [open a private security advisory](https://github.com/teenybase/teenybase/security/advisories/new). Do not open a public issue.

Include what you found, how to reproduce it, and the impact you expect. We aim to acknowledge reports within 48 hours and to ship a fix for critical issues within 7 days. We credit reporters unless they ask us not to.

## Supported versions

Teenybase is pre-1.0. Security fixes go into the latest published release only.
